# Visual Spa Hair

Site institucional responsivo do salão **Visual Spa Hair**, localizado no centro de Foz do Iguaçu, Paraná.

## Visualizar o site

[Abrir Visual Spa Hair](https://visual-spa-hair-foz.eduardogps2503.chatgpt.site)

## Páginas

- Início
- Serviços
- Resultados
- Sobre
- Contato e agendamento pelo WhatsApp

## Tecnologias

- React
- TypeScript
- HTML e CSS responsivos
- vinext / Vite

## Desenvolvimento local

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

O servidor local ficará disponível em `http://localhost:3000`.

## Validação

O site foi verificado em larguras de celular (390 px), tablet (768 px) e desktop (1440 px), incluindo todas as páginas, menu móvel, imagens e ausência de rolagem horizontal.
